# Challenge: WhatsApp Data Fetcher

## Objective

Build a program in Python that connects to a WhatsApp group, fetches as many messages as possible, and stores them in a database.

## Deliverables

- Fetch messages from a WhatsApp group (any group works — including one with just yourself)
- Store those messages in a database

## Constraints

- Backend in Python
- No authentication required for the service itself

## Bonus

- Containerize the application with Docker
- Use PostgreSQL as the database
- Use Flask or FastAPI to create a webhook that receives messages in real time

## Suggested Approach

[WAHA](https://waha.devlike.pro/) is a useful tool for simplifying WhatsApp integration — worth looking into if you haven't worked with the WhatsApp API before.

## README

Your README should answer:

1. How to run and test the project
2. How you handled the WhatsApp integration and why
3. What you would build next if this were a real product

## What We're Looking For

A clean implementation matters, but it's secondary to your reasoning. Why you made the choices you did, and what you'd do next, tells us more than the code alone.
